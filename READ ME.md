MOODFIT – Mood-Based Fashion Recommendation System



1\. Project Overview



MoodFit is a Python-based mood-based fashion recommendation system that suggests suitable clothing based on the user's personal information, current mood, weather conditions, and occasion.



The system follows a modular approach where different modules collect different types of user input. These inputs are then combined in the final recommendation module to provide a suitable fashion recommendation.



The main purpose of MoodFit is to make clothing selection easier by considering both the user's preferences and the surrounding conditions.



2\. Problem Statement



Choosing an appropriate outfit can sometimes be difficult because clothing choices depend on several factors such as mood, weather, occasion, and personal preferences.



MoodFit addresses this problem by collecting relevant information from the user and processing it through different modules to generate a suitable clothing recommendation.



3\. Objectives



The main objectives of MoodFit are:



\- To create a simple and interactive fashion recommendation system.

\- To collect relevant user information.

\- To consider the user's current mood while recommending an outfit.

\- To consider weather conditions while selecting clothing.

\- To consider the occasion while generating the recommendation.

\- To demonstrate modular programming concepts using Python.

\- To provide a simple and user-friendly command-line interface.

\- To practice functions, lists, conditional statements, loops, input validation, and modules.


MoodFit provides the following features:



\- User information input.

\- Mood selection.

\- Weather selection.

\- Occasion selection.

\- Combined fashion recommendation.

\- Interactive command-line interface.

\- Input validation for menu choices.

\- Modular program structure.

\- Personalized clothing recommendations based on multiple inputs.


The project consists of five major modules:



Module 1 – User Information



This module collects basic information from the user, such as:



\- Name

\- Age



Module 2 – Mood Selection



This module allows the user to select their current mood from the available options.



Example moods include:



\- Happy

\- Chill

\- Romantic

\- Confident

\- Energetic

\- Cozy

\- Sexy



Module 3 – Weather Selection



This module collects the current weather condition from the user.



Available options include:



\- Hot

\- Warm

\- Chilly

\- Rainy



Module 4 – Occasion Selection



This module allows the user to select the occasion for which they need an outfit recommendation.



Module 5 – Fashion Recommendation



This is the final module.



It combines the information collected from the previous modules:



User Information + Mood + Weather + Occasion



The system then generates an appropriate fashion recommendation.





6\. System Workflow



The workflow of MoodFit is:



1\. Start the program.

2\. Display the MoodFit welcome message.

3\. Collect the user's basic information.

4\. Ask the user to select their mood.

5\. Ask the user to select the weather condition.

6\. Ask the user to select the occasion.

7\. Combine all the collected inputs.

8\. Generate a suitable clothing recommendation.

9\. Display the recommendation.

10\. End the program.
